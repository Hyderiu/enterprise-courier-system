# 功能清单

## 员工端

- 根据登录人的工作地点进入对应地区下单页。
- 单票寄件与批量寄件。
- 部门费用/项目费用搜索选择。
- 承运商产品切换、报价和预计送达查询。
- 我的订单、物流轨迹、撤回/修改允许范围控制。
- 系统外运单补充记录，仅管理自己的记录。
- 地址簿与意见建议。

## 审批端

- 待审批优先展示。
- 单票、批量寄件、运单补充记录分类查看。
- 一级/二级审批与审批历史。
- 批量单总金额、逐票金额和预计送达展示。
- 管理员在后台总单中执行授权范围内的审批跳过操作。

## 管理端

- 全部快递单、筛选、详情、物流刷新与受控删除。
- 运单补充记录管理。
- 费用账单导入、匹配、人工补全、保存与三类导出。
- 月度费用可视化：地区、快递、时间范围、费用结构和匹配来源。
- 成员与权限、审批流程、企业寄件地址、物品类型和默认快递推荐。
- CRM 项目/部门只读展示与手动刷新。
- 承运商接口、地区店铺和结算配置。

## 外部集成

- 顺丰丰桥：产品、报价、下单、取消、路由与费用。
- 顺丰同城：店铺、预下单、报价、正式下单、回调和骑手状态。
- 德邦：小件/大件产品、报价、下单、取消、轨迹和实际费用。
- 京东物流：标快/大件、报价、下单、取消、轨迹和费用。
- 钉钉：免登、身份、组织信息与审批提醒。
- CRM：项目、项目编码、执行部门完整路径、部门编码和全量部门。

## 公开版限制

- 不提供任何企业凭证、内部接口地址或真实结算配置。
- 演示模式不允许真实下单、取消或其他写入承运商的操作。
- 示例数据不代表真实员工、客户、账单或经营情况。
- 正式部署、反向代理、TLS、备份和监控需要按所在企业基础设施补充。
